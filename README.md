# Ollama Llama 3.2 Local AI Project

## Overview

This project demonstrates how to run the Llama 3.2 AI model locally using Ollama and interact with it through Python.

## Technologies Used

- Python
- Ollama
- Llama 3.2

## Setup

1. Install Ollama.
2. Download the Llama 3.2 model:

```bash
ollama pull llama3.2
